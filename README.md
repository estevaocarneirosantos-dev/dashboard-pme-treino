# Dashboard PME Treino — Barbearia Corte Fino (fictícia)

Projeto de treino backend Node + Express até janeiro/2027.
Simula uma dashboard real para pequena empresa: clientes, agendamentos, serviços e financeiro simples.

## Cliente fictício
**Barbearia Corte Fino** — micro-empresa: precisa de organização de clientes, agendamentos, serviços e contas a receber.

## Estrutura profissional
- `backend/` — API Node + Express (começa com `/clientes`)
- `frontend/` — dashboard (vai ligar na API em dez)
- `docs/` — plano até janeiro

## Como rodar (backend)
```powershell
cd backend
npm install
node server.js
```
Abre `http://localhost:3001/clientes`
